# ByteBites Design Reference

## Behavioral Instructions
(Fill in after seeing the unguided draft. Suggested rules below.)

- Model only the four classes in the spec: Customer, MenuItem, Menu, Order.
- Do not add extra classes (no Payment, Restaurant, Recommender, User, Cart).
- Use plain Python classes and built-in containers only. No inheritance, no external libraries.
- Include only attributes named in the spec.
- Keep methods small, readable, with simple type hints.
- Prefer scaffolds and short methods over production-style code.
- Ask before adding any feature the spec does not mention.
